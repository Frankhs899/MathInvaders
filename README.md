# Math Invaders

A 2D browser-based game inspired by Space Invaders with a math theme. Practice addition, subtraction, multiplication, and division while defending against waves of math problems.

## Features

- Choose your math operation: Addition, Subtraction, Multiplication, or Division
- Three difficulty levels: Easy, Medium, Hard
- Retro arcade aesthetic with neon visuals

## Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm

### Installation

```bash
npm install
```

### Run the game

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for production

```bash
npm run build
```

## Tech Stack

- [Phaser 3](https://phaser.io/) — Game framework
- [Vite](https://vitejs.dev/) — Build tool
